# Digitalpakt
Der Digitalpakt 2.0 zielt darauf ab, die bisherigen Erfolge des DigitalPakt Schule zur digitalen Transformation von Schule auszuweiten und zu vertiefen. Dazu beinhaltet und verknüpft der Digitalpakt 2.0 die Weiterentwicklung der schulischen Infrastruktur mit pädagogischer Weiterentwicklung auf neue Weise.
